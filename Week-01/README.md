## What I learned

- A repository is where all the commits get stored. It's basically a record of the series of changes to the project.
- A README file helps explain what the code in a repo or particular folder does and how to work with it.
- A commit records who did it, when (data/time), and what they changed in the code files.
- One question I still have is how to handle merge conflicts.
